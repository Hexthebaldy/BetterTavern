# BetterTavern 网页端 · 漫画分镜版

这是电脑浏览器端的新界面，从“白 / 柔线 / 大圆角”换成落地页那一套漫画风：墨黑粗描边、硬投影、网点、宋体粗标题，交互往游戏靠。顶栏和侧栏都去掉了，导航收进一只可以拖动的轮盘。

状态：01–09 已经实现（2026-10-24），10–12（登录、注册、验证邮箱）也已经实现（2026-10-24）；实现说明在 [docs/client.md 第 4 节](../../client.md)，和稿子不一样的地方也记在那里。给 Claude Code 的重构提示词在 [`refactor-prompt.md`](refactor-prompt.md)，登录页的在最后的“追加”一节。

画板按 1440×900 的浏览器视口画。窗口窄于 900（平板、手机）的情况这一版没有出稿，先沿用现在的布局。

在线画布的第 14 节是这一版（“漫画分镜 · 轮盘导航”）。第 13 节是选方向时的三版试稿（主菜单、漫画分镜、卡牌桌游），最后选了漫画分镜。画布需要作者的账号才能打开：

## 轮盘

| 项 | 规则 |
| --- | --- |
| 收起 | 一个直径 72 的圆：白底，2.5 描边，`--x4` 投影，中间是 36 的 Logo，没有别的装饰。默认贴着窗口左边、上下居中（圆心离左边 52） |
| 页面留边 | 轮盘贴着哪一边，页面那一边就留 112（圆的宽度加 24 的空）；拖到中间、不贴边的时候，两边都只留 40，轮盘浮在内容上面 |
| 展开 | 鼠标在圆上停 120ms 就展开，不用点。底下是一块白色圆盘：半径 178，2.5 描边，7px 硬投影。圆盘上有 6 块扇区，每块 60°，内半径 52、外半径 156，各自往外挪 4px 留出缝。从正上方开始顺时针依次是：存档、剧本、角色、工作台、模型、设置。中心的圆变成墨底，Logo 反白 |
| 每块的内容 | 在半径 102 处放图标（24）、名称（15.5，粗）和数量（等宽 10.5）。数量的例子：存档 12、剧本 24、角色 12、工作台“草稿 2”、模型“5 个”，设置不写。数字键 1–6 的键帽（22 见方，白底描边）印在圆盘外圈，半径 168 |
| 状态 | 当前所在的那一页：墨底，字反白，数量是浅蓝。鼠标指着的那块：蓝网点底，再往外弹出 14px，带 6px 硬投影，描边 3；它的键帽也跟着往外挪，变成墨底。旁边冒一个气泡，写这一项是干什么的和数量（比如“挑一个剧本，开新的一局 · 24 个”） |
| 靠边时 | 圆盘要整圈露在窗口里，所以圆心离窗口每条边至少要有 204。离边太近时，展开前先把圆心挪到够远的位置（240ms），收起时再挪回原位。挪完以后光标底下正好压着某一块，所以要等鼠标动一下才开始高亮，免得一展开就选中 |
| 放在中间时 | 圆心离边够远就原地展开，光标正好在圆心。选哪块按角度算：光标离圆心超过内半径以后，往哪个方向偏就是哪块，不用真的碰到扇区 |
| 选择 | 单击扇区进入那一页；按 1–6 直接去；按 Enter 进入当前高亮的那块 |
| 收起 | 鼠标离开圆盘 1 秒后收起，这期间移回来就不收；按 Esc、点页面别处、进了新页面都立刻收起。展开时圆盘从 0.88 倍放大、淡入（240ms），收起时缩回去、淡出（220ms） |
| 拖动 | 在圆上按住 0.4 秒就拿起来：圆放大到 1.12 倍，投影变成 `--x8`，光标变成抓手，原来的位置留一个虚线圈。松手就停在那里；松手时离左边或右边 40 以内会贴边（圆心离边 52）。位置存在这台设备上（localStorage），下次打开还在。按住不到 0.4 秒就移开的，算悬停，不算拖动。贴边展开时圆心已经挪开了，所以在展开的圆盘上任何地方按住 0.4 秒也能拿起来，圆跳到光标底下；点一下扇区还是进入那一页 |
| 键盘 | Q 在轮盘当前的位置打开或收起；1–6 直接去；← → ↑ ↓ 在 6 块之间转，Enter 进去，Esc 收起。单键快捷键跟着设置里的开关走（关掉以后只剩 Esc），光标在输入框里时不响应 |
| 触屏 / 没有悬停 | 点一下圆展开，点扇区进去，点空白处收起；长按拖动 |
| 无障碍 | 圆是一个按钮（`aria-haspopup="menu"`、`aria-expanded`），展开后的 6 块是 `menu` / `menuitem`；打开时焦点落在当前页那一块。开了 `prefers-reduced-motion` 时不做弹出和位移的动画 |

## 页面结构

- 没有顶栏，也没有侧栏。页头是一行：左边是页标题（宋体 900，40/48）加一个数量标签，右边是这一页的工具（搜索、筛选、主按钮）。页头离窗口顶 36，高 48。
- 内容从离顶 112 的地方开始，左边离窗口 112（给轮盘留的边），右边离 40。
- 一级页用“漫画格子”排：6 列 × 3 行，格子之间空 14。最近、最重要的东西占大格，其余的占小格，一页排满，翻页（底部写“— 01 —”和“下一页 →”，← → 也能翻），不无限滚动。
- 格子的高度跟着窗口：3 行分掉页头和页码之外的高度，每行至少 200；窗口太矮时整页滚动。窗口很宽时内容最宽 1600，居中。
- 搜索：设计稿右上角的“⌘K”是以后要做的全局搜索，这一版不做。页头的搜索框只放在已经有搜索的页面（剧本、角色）。

## 和现在的代码不一样的地方

- 侧栏（`shell/Sidebar.tsx`）和收起后的窄条都不要了，侧栏里“最近的存档”也不要了，存档页本身就是按最近排的。快捷键 `[`（展开或收起侧栏）换成 Q（轮盘）。
- 账户小窗（`AccountMenu`）里的东西搬进设置页的“账户”一格。
- 外部服务从一级导航降成设置的子页面：`/settings/tools`，旧地址 `/tools` 跳过去。
- 设置页的“阅读”一格就是现在阅读页里的阅读偏好（`@bettertavern/core/play/reading` 的字号、行距），在这里也能改。

## 要定的事

1. 夜间模式：设计稿只画了浅色。建议墨和纸对调（纸 `#111113`，墨 `#F2F2F0`），蓝用 `#8597FF`。硬投影在深色底上看不清，可以改成纯黑再加 1px 浅色描边，需要出一张夜间的稿来定。
2. 窄于 900（平板、手机）：这一版先沿用 Tab 栏；漫画版的手机布局要另外出稿。
3. 人物头像：角色卡没有头像时用大字占位；以后要不要让工作台生成头像，再定。
4. 轮盘上的数量：要用到存档、剧本、角色、草稿、模型五个列表的数量，没加载到时先不显示数字。
