# BetterTavern 手机端 · 漫画风格

这是手机端（`apps/mobile`）的新界面：风格换成和网页端（[`../README.md`](../README.md)）同一套漫画风，墨黑粗描边、硬投影、网点、宋体粗标题；**页面结构和布局沿用现在竖屏的方案**（[`docs/design/ui/`](../../ui/README.md)），只换风格。平板横屏见 [`../tablet/`](../tablet/README.md)；平板竖屏（窗口 600–899）用这里的样式套现在平板中屏的布局。

状态：设计稿（2026-10-24，10-25 改过：Tab 栏的“剧本”改叫“库”；开始新故事的第 2 步只有输入框），还没有实现。给 Claude Code 的重构提示词在 [`refactor-prompt.md`](refactor-prompt.md)，手机和平板一起。

画板按 390×844 的手机屏画。在线画布的第 15 节是这一版（“手机 · 漫画风格”）。画布需要作者的账号才能打开：
https://claude.ai/artifact/X9AHDCGAN7fs7mCHEUUvZc

## 和现在的代码不一样的地方

- 主题：从“白 / 柔线 / 大圆角”换成粗线版。描边、硬投影、圆角这些变量可以照网页端的写法加进 `packages/design`，手机和网页共用；色板（`palettes.ts`）里的 `bg` 不改，页面底色单独一个变量。
- 卡片：现在是白底上的浅灰圆角卡，改成浅灰页面上的白底墨线格子。
- Tab 栏：位置、浮层、四块都不变，第二块改叫“库”；样子换成白底墨线加硬投影。滑动的选中框（iOS 26 的液态玻璃、其他平台的蓝色细描边框）都去掉，选中改成实心蓝图标加粗字。
- 阅读页的“我的行动”：现在是浅一档的颜色加一道灰线，改成和正文同色、左边一道蓝线。
- 选项：现在是浅灰圆角行，改成灰底墨线格子加硬投影。
- 工作台的改动对比：换成和网页一样的酒红、深绿。
- 字体：标题要用宋体 900。现在只打包了 `NotoSerifSC-Regular`（GB2312 子集，约 3.2 MB）和日文的 Regular；等宽现在有 400、500，稿子里的数量和标签是 700。

## 要定的事

1. 宋体粗体：再打包一份 Noto Serif SC Black 的子集只给标题用（安装包会变大），还是标题先用系统的粗黑体顶替。
2. iOS 26 的液态玻璃：稿子里 Tab 栏不用玻璃。如果想保留系统的玻璃质感，就只能保留现在的样子，和漫画风不一致。
3. 平板竖屏（600–899）：没有单独出稿，用手机的样式套现在平板中屏的布局（居中单栏、底部 4 块）。横屏见 `../tablet/`。
4. 图片：封面候选、参考图、角色卡头像在稿子里是灰色占位；有图时直接放进格子（2 墨线、圆角 10），不加滤镜。
