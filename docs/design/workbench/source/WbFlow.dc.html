工作台

创建、导入和修改角色卡都在这里。没人想费劲设计一张角色卡，所以默认由 agent 来做：一句话说要什么，它先问清楚、出方案，确认后自己动手写，作品里的角色它会自己查资料、找图；想精确控制时切到手动，改的是同一份草稿。剧本页不再有导入。

五条原则

每个界面都按这几条来定。

01一句话就能开始输入框就是入口，给几条例子；不用先选“原创还是作品”，agent 自己判断。
02先问清楚再动手像 plan 模式：先出一份问卷，再出方案，确认了才写。不会写到一半才发现方向不对。
03每题都有推荐问卷最多 6 题，每题都替你选好推荐答案；一键“就按这些”，也可以全交给它。
04活都由 agent 干起名字、写设定、写开场、整理世界书、查资料、找图、生成封面、按导入规则检查。
05改动先给你看写的过程实时可见、随时能停；之后的修改用对比显示，采用了才写进卡片。

入口

新的一栏“工作台”，放在“剧本”和“设置”之间。

从工作台开始

  • 一句话：进 Agent 模式，按下面的流程走。
  • 导入角色卡：PNG 或 JSON，可以多张；导入后直接进剧本库，不用再确认，想改再点“改一改”。
  • 手动新建：空白表单，随时可以切到 Agent。
  • 草稿：没保存的都在这里，写一半退出也不丢；状态写明“等你回答”“方案等你确认”。

从别处进来

  • 剧本详情 → 编辑角色卡：在工作台里打开这张卡，默认上次用的模式。
  • 剧本页：去掉右上角的导入；第一次进来提示一次“挪到了工作台”。空的剧本库引导去工作台。
  • 保存：保存到剧本库后才能开始故事；也可以“保存并开始新故事”一步到位。改已有的卡只影响之后开始的故事。

Agent 的流程

蓝色是要用户做决定的地方，其余都是 agent 自己做。

原创“想要一个开在城隍庙边上的当铺掌柜”
理解判断要什么原创还是作品角色；已经说清楚的不再问
→
问卷确认需求最多 6 题，每题有推荐；可跳过、可“交给你”
→
方案确认方案名字候选、一句话设定、性格、世界书条目、开场、封面
→
动手一项项写实时出现在卡片上，可以随时停
→
检查按导入规则查和导入、手动保存用同一套规则；不合格自己改
→
完成保存或接着改改动用对比显示，采用了才算
作品角色“《红楼梦》里的林黛玉，我以宝玉的身份陪她过元宵”
资料先自己查联网搜索、读原文和百科、找图，记下每条用在哪里
→
问卷只问你能定的哪个时期、你扮演谁、文风、封面用哪张
→
方案确认方案附资料来源；原著没有的设定不添
→
动手照原著写拿不准的地方写进作者备注
→
检查按导入规则查来源写进作者备注
→
完成保存或接着改同上

Agent 能用的工具

都在服务端跑，过程写进干活记录，用户看得到每一步。

ASK问卷出选择题，带推荐答案；用户答完才继续
WEB联网搜索、读网页查作品资料；记下来源和用途
IMG找图标出公有领域和有版权的图，有版权的只作参考
GEN生成封面文生图，一次 4 张；可以改提示词和风格重来
CARD写卡片按字段写：基本、描述、性格、情境、开场白、对话示例、世界书
DIFF改卡片改已有的卡时给出对比，用户采用才写入
CHK检查和导入、手动编辑用同一套规则（cardEdit）
SAVE存草稿每一步都存，退出再进来接着做

要补的设置和要定的事

这些不在工作台的界面上，但不定下来做不了。

设置

  • 工作台用哪个模型：默认用导演模型；要能调用工具。可以单独选一个更强的。
  • 联网搜索：配一个搜索服务和 Key（或者用服务商自带的搜索）。没配时只能用模型自己知道的，作品角色会提示“没法查资料”。
  • 生成封面：模型详情里加一个“用于生成封面”的开关，只对能生图的模型开放。没配时封面用几何封面。

要定的事

  • 作品角色的图：有版权的图默认不拿来做封面，只作参考；用户坚持要用时提示仅限个人使用。
  • 草稿存哪：存服务端，跟账户走，手机和网页都能接着做。
  • 费用：查资料和生图要花钱，开始前在方案里写上大概要调用几次。
