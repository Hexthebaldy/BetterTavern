# BetterTavern 工作台

工作台是 App 新加的一栏，创建、导入和修改角色卡都在这里。没人想费劲设计一张角色卡，所以默认由 agent 来做：用户说一句想要什么角色，agent 先问清楚、出方案，确认后自己动手写；作品里的角色，它先自己查资料、找图。想精确控制时切到手动，两种模式改的是同一份草稿。剧本页不再有新建和导入。

设计稿画了手机（390×844）和电脑 Web 端（视口 1440×900）。颜色、圆角、字体和部件沿用 App 的柔和圆角版：手机见 `docs/design/ui/`，电脑见 `docs/design/ui/web/`。

状态：设计稿，还没实现。后端草案在 [`docs/workbench.md`](../../workbench.md)，有几处和设计稿不一致，见最后“和后端草案对不上的地方”。

## 原则

1. **一句话就能开始。** 输入框就是入口，下面给几条示例；不用先选“原创还是作品”，agent 自己判断。
2. **先问清楚再动手。** 像 Claude Code、Codex 的 plan 模式：先出问卷，再出方案，确认了才写。不会写到一半才发现方向不对。
3. **每题都有推荐。** 问卷每题都预先选好推荐答案，一键“就按这些，出方案”，也可以“都交给你”。
4. **活都由 agent 干。** 起名字、写设定、写开场、整理世界书、查资料、找图、生成封面、按导入规则检查。
5. **改动先给你看。** 写的过程实时可见、随时能停；之后的修改用对比显示，采用了才写进卡片。

## 流程

agent 自己判断是原创还是作品里的角色，两条流程只差前几步。加粗的是要用户做决定的地方（`WbFlow.png` 上是蓝色），其余都是 agent 自己做。

| 步骤 | 原创 | 作品角色 |
| --- | --- | --- |
| 1 | 理解：判断要什么，已经说清楚的不再问 | 资料：先自己查，联网搜索、读原文和百科、找图，记下每条用在哪里 |
| 2 | **问卷**：最多 6 题，每题有推荐；可以跳过，可以“都交给你” | **问卷**：只问用户能定的，哪个时期、你扮演谁、文风、封面用哪张 |
| 3 | **方案**：名字候选、一句话设定、性格、世界书条目、开场、封面 | **方案**：附资料来源；原著没有的设定不添 |
| 4 | 动手：一项项写，实时出现在卡片上，可以随时停 | 动手：照原著写，拿不准的地方写进作者备注 |
| 5 | 检查：和导入、手动保存用同一套规则；不合格自己改 | 检查：同左，来源写进作者备注 |
| 6 | **完成**：保存，或者接着改 | 同左 |

- 进度条：原创是“需求—方案—动手—检查”四步，作品角色前面多一步“资料”。
- 改已有的卡：从剧本详情点“编辑角色卡”，在工作台里打开这张卡，默认用上次的模式。改动不再走问卷和方案，直接出对比。

## 交互

- **模式切换**：页头的“Agent / 手动”。两种模式看的是同一份草稿，切换不丢东西。
- **问卷**：单选题点一下换选项；多选题标“可多选”；“其他…”可以自己写一句。答完以后，问卷在对话里收成一行摘要（“答了 6 题 悬疑 · 民国 · …”）；方案确认后也收成一行（“方案已确认 … 展开”）。
- **卡片预览**：手机上是页头右边的按钮，有新内容时带蓝点；电脑上常驻在右栏。新写的字段蓝底，待采用的改动绿框。
- **进度清单**：做完的打勾，正在做的是蓝圈，没做的是灰圈。点“停止”，agent 做完手上这一步就停。
- **输入框**：agent 写的时候提示“写完以后可以接着提要求”；写好以后是“还想改哪里？”，上面给几条建议（“开场更快进入事件”“多写两条世界书”……）。
- **对比**：删掉的红底加删除线，新写的绿底。“全部采用”写进卡片，“逐条看”一处一处决定，“都不要”丢掉这次改动。
- **封面**：选中的一张蓝框加勾。风格单选（水墨、油画、胶片、平涂），改了提示词或风格再生成。生图模型可以在这里换。
- **图片**：查到的图标“公有领域”或“有版权”；有版权的图灰掉、带锁，只作参考，默认不能选成封面。
- **保存**：卡片没写好时“保存到剧本库”不能点；写好以后也可以“保存并开始新故事”，一步到位。改已有的卡只影响之后开始的故事。
- **草稿**：每一步都自动保存，写一半退出也不丢；草稿按最近改动排，写明在等什么。
- **剧本页**：第一次进来提示一次，点“去看看”进工作台，点叉以后不再提示。剧本库是空的时候，空状态引导去工作台。

## 要补的设置

- **工作台用哪个模型**：默认用导演模型，必须支持调用工具；可以单独选一个更强的。
- **联网搜索**：配一个搜索服务和 Key（或者用服务商自带的搜索）。没配时只能用模型自己知道的，作品角色会提示“没法查资料”。
- **生成封面**：模型详情里加一个“用于生成封面”的开关，只对能生图的模型开放。没配时封面用现在的几何封面。

## 要定的事

- **作品角色的图**：有版权的图默认不拿来做封面，只作参考；用户坚持要用时，提示仅限个人使用。
- **草稿存哪**：存服务端，跟账户走，手机和网页都能接着做。
- **费用**：查资料和生图要花钱，开始前在方案里写上大概要调用几次。

## 和后端草案对不上的地方

后端草案 [`docs/workbench.md`](../../workbench.md) 和设计稿是同时写的。工作台用的模型两边一致（默认用导演，可以单独选），下面几处不一致，实现前要定下来：

| | 设计稿 | 后端草案 |
| --- | --- | --- |
| 卡放在哪 | 保存到剧本库，沿用现在“一个剧本就是一张卡” | “剧本”拆成角色卡仓库和剧本仓库；工作台做的卡、导入的卡都进角色卡仓库，剧本从里面选卡新建 |
| 剧本页的加号 | 去掉，新建和导入都在工作台 | 剧本仓库保留加号，用来从角色卡新建剧本 |
| 什么时候进库 | 写好以后点“保存到剧本库”，在那之前是草稿 | 方案确认后 agent 直接建卡，每一轮做完存一份修订 |
| 修改 | 先给对比，采用了才写进卡片 | 直接改，可以“撤回这一轮” |
| 问卷 | 最多 6 题；推荐项预先选好、标“推荐”，位置不固定；“都交给你” | 最多 5 题，每题最多 4 个选项，第一个是推荐项；界面另加“其他（自己写）”和“跳过，直接做” |
| 导入在哪 | 工作台首页 | 手动模式里 |
| 搜索和生图的设置 | 单独配搜索服务；模型详情里加“用于生成封面”的开关 | “外部服务”统一配搜索、读网页和文生图，按接口协议接，可以测试 |
