宽屏：左侧导航栏

一条竖着的浮动胶囊，顶上是 Logo，下面三个标签。选中项是墨色圆角块，图标在上、文字在下。只出现在三个一级页（故事、剧本、设置）；进入阅读页、剧本详情这类二级页后隐藏，和手机上 Tab 栏的规则一样。

中屏：底部胶囊，宽度固定

沿用手机的浮动 Tab 栏，宽度固定 392 并水平居中，离底 28 加安全区。不要拉满屏宽，否则三个标签之间会空得很远。

二级页的返回

二级页左上角仍是 40 的灰色圆形返回按钮。在宽屏的两栏页面里（设置），右栏内部再往下钻一层时，右栏顶部显示上一层的名字加返回箭头，左栏不动。

Reading

阅读页

宽了以后最容易做错的地方是把正文拉宽。不要这样做。

正文最宽 640，居中

叙述、“我的行动”卡片、状态行都在这条栏里。字号仍由阅读设置决定；屏幕再宽，栏也不变宽。

行动面板跟着阅读栏

面板宽 672，和阅读栏同一条中线，离底 20。宽屏上选项排成两列，横屏时少占一半高度；奇数个时最后一项占满一行。中屏仍是一列。

世界状态停靠时

阅读栏在剩下的区域里居中，行动面板跟着移过去。世界按钮显示为选中（墨色），再点一次收起。开关状态记在本地，下次打开故事时保持。
