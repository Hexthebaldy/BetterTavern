# BetterTavern 平板 UI · 响应式布局（柔和圆角版）

这一份是 `apps/mobile` 在平板上的设计稿。颜色、圆角、字体、组件全部沿用上一级目录（`docs/design/ui/`）的手机设计稿和 `tokens.ts`。本目录只规定一件事：窗口变宽以后，布局怎么变。

**实现方式是同一套代码做响应式，不另写一套平板页面。** 每个页面根据窗口宽度选择布局。

## 先改配置

现在 `app.config.ts` 是 `orientation: "portrait"` 和 `ios.supportsTablet: false`。要支持平板，需要：

1. **打开平板支持：** `ios.supportsTablet: true`。
2. **平板支持所有方向，手机仍锁竖屏。** iPad 要参与分屏和台前调度，就必须声明支持所有方向。建议做法：
   - 把 `orientation` 改成 `"default"`；
   - 用 `expo-screen-orientation`（`npx expo install expo-screen-orientation`）在启动时判断：屏幕短边 < 600 时锁定竖屏，其余不锁。
   - iOS 也可以改用 `ios.infoPlist` 分别声明 `UISupportedInterfaceOrientations`（只放竖屏）和 `UISupportedInterfaceOrientations~ipad`（放全部四个方向）。

   以上请按 Expo SDK 57 的文档核对后再实现。

## 断点：只看窗口宽度

| 名称 | 窗口宽度 | 典型场景 | 布局 |
| --- | --- | --- | --- |
| 窄 `compact` | < 600 | 手机；平板分屏最窄的一栏 | 手机设计稿原样 |
| 中 `medium` | 600–899 | iPad 竖屏（744、834）；分屏一半 | 内容收进居中单栏（≤ 640）；Tab 栏仍在底部，宽 392 居中 |
| 宽 `expanded` | ≥ 900 | iPad 横屏；13 寸竖屏 1032 | 左侧浮动导航栏；设置、剧本详情两栏 |
| 阅读页停靠 | ≥ 1100 | iPad 横屏 | 世界状态停靠在右侧 |

- 用 `useWindowDimensions().width` 配合 `sizeClass()` 判断，不要用 `Platform.isPad`，也不要判断横竖屏。
- 窗口尺寸变化时（旋转、分屏拖动）布局要即时切换，并且保留当前状态：草稿、滚动位置、已打开的故事。

## 实现要点

### 1. 导航

- **宽屏：左侧导航栏。** `TabBar`（`components/bars.tsx`）在宽屏改画一条竖着的浮动胶囊：
  - 位置：左 16、顶 32，宽 76，圆角 38；
  - 顶部是 Logo，下面三个标签；
  - 选中项是墨色圆角块，60×64、圆角 30，图标在上、文字在下；
  - 高度随内容，不拉满；
  - 一级页的内容从 x = 124 开始，右边距 40。

  `useTabBarSpace()` 要随之改成返回左侧留白，底部不再留白。
- **中屏：底部胶囊。** 沿用现有 Tab 栏，宽度固定 392 并水平居中，不要拉满屏宽。
- **二级页**（阅读页、剧本详情、设置子页、连接测试）不显示导航栏，这一点和手机一致。
- **切换动画：** 标签切换的淡入淡出、胶囊动画在宽屏同样适用；导航栏里选中块的移动改成纵向。

### 2. 栏宽

所有栏宽都在 `layout.ts` 的 `pane` 里：

| 用途 | 宽度 |
| --- | --- |
| 阅读栏、表单、单栏页面（上限） | 640 |
| 阅读页底部操作栏的内容 | 672 |
| 设置左栏 | 340 |
| 剧本详情信息栏 | 420 |
| 世界状态面板 | 400 |
| 居中对话框（上限） | 480 |
| 弹出菜单 | 340 |
| 提示浮条（上限） | 480 |

`Page` 组件建议加一个 `maxWidth` 参数（默认 640），在中屏和宽屏把内容居中。

### 3. 浮层（`components/overlay.tsx`）

`Sheet` 按 `overlayPresentation(kind, sizeClass)` 换形态：

- **对话框：** 服务器、外观、重命名、确认删除、揭示秘密，在中屏和宽屏都变成居中对话框。
  - 宽 ≤ 480，圆角 32，四周留白 16；
  - 没有拖拽条，右上角有关闭按钮；
  - 点遮罩关闭。
- **弹出菜单：** 阅读页“更多”菜单贴着触发按钮弹出。
  - 宽 340，圆角 28，右边缘和按钮右边缘对齐，底边在按钮上方 8；上面放不下时改到按钮下方；
  - 不加遮罩，点外面关闭；
  - 打开时触发按钮显示为选中（墨色）。
  - 按钮位置用 `ref.measureInWindow()` 取得；量不到时退回居中对话框。
- **提示浮条：** 宽 ≤ 480。中屏贴在底部 Tab 栏上方，宽屏在内容区（x ≥ 124）底部居中，离底 32。
- **键盘：** 对话框里有输入框时，对话框跟着键盘上移，沿用 `useKeyboardLift`。

### 4. 阅读页（T05–T10）

- **阅读栏：** 最宽 640，用 `readableColumn(available)` 计算位置。
  - 叙述、“我的行动”、接在正文后面的选项、开场的书名卡（`BookHeader`）都在这条栏里；
  - 字号仍由阅读设置决定，栏宽不随字号变化；
  - 导航栏的标题和阅读栏中线对齐，返回按钮仍在左上角。
- **选项：** 接在正文后面（画板 T05–T07 里还在底部面板里，已经改掉，见上一级 README 的“阅读页要点”）。
  - 宽屏下排成 2 列网格，每格最小高 76；选项数为奇数时，最后一项占满一行。
  - 中屏下仍是一列。
- **底部操作栏：** 贴着屏幕底边、铺满阅读区，里面的内容宽 672，和阅读栏中线对齐。左边世界、右边更多，中间是“自己写…”或生成状态和“停止”，和手机一样。
- **世界状态**，用 `worldPresentation(width)` 判断形态：
  - **≥ 1100，停靠：**
    - 面板在右侧，宽 400，上、下、右各留 8，圆角 32，底色 `bg2`，不加遮罩；
    - 实体卡片改用白色 `card` 底；
    - 阅读栏和底部操作栏在剩下的宽度（`width − 408`）里重新居中；
    - 世界按钮显示为选中（墨色底、白色图标），再点一次收起；
    - 面板右上角有收起按钮（侧栏图标）。
    - 停靠时的开关状态存到 `PrefsProvider`，下次打开任意故事时保持。
  - **600–1099，滑出：** 从右侧滑出，宽 400，上、下、右各留 8，圆角 32，有遮罩。右上角的关闭按钮是 ×。
  - **< 600：** 现有的底部面板。
  - **揭示秘密的确认框：** 在任何形态下都是居中对话框（宽 ≤ 480），盖在世界面板之上。
- **自由输入：** 点“自己写…”在操作栏里原地展开，键盘弹起时跟着上移，沿用 `useKeyboardLift`，阅读栏的底部留白也跟着变。iPad 横屏的键盘大约占 400 高，故事流只剩一两段可见，这是正常的。
- **滚动跟随、流式光标、读屏朗读：** 逻辑全部不变。

### 5. 故事列表（T03、T04）

- **列数：** 用 `storyColumns()`，窄 1 列、中 2 列、宽 3 列，卡片之间间距 12。
- **最近一个故事**（列表第一项）放大成主卡：
  - 中屏占满一行、高两行；宽屏占两列两行；
  - 主卡内容：封面 132–148、标题 26、状态胶囊，最新一段正文用宋体 18/32、最多 4 行，底部是“继续读”按钮；
  - 数据和现有列表项相同，不需要新接口。
- **重命名和删除：**
  - 中屏保留左滑；
  - 宽屏改为长按，卡片抬起（放大 3%，白底加投影），下方弹出菜单（宽 240），背景加浅遮罩 `rgba(20,20,20,.18)`；
  - 两种屏宽都支持长按。
- **下拉刷新、空状态、加载失败提示：** 都放在内容栏里，宽度不超过 640，居中。

### 6. 剧本库与剧本详情（T11、T12）

- **剧本网格列数：** 用 `libraryColumns()`，宽屏按内容宽度 ÷ 240 取整，最多 5 列，间距 16。列表视图在中屏和宽屏都限宽 640、居中。
- **导入按钮：** 宽屏上从圆形 + 号换成带文字的胶囊“导入角色卡”。导入中的禁用态和提示浮条不变。
- **剧本详情宽屏两栏：**
  - 左栏宽 420：封面（236 高，返回按钮浮在封面上；设计稿里的“更多”已去掉）、名字、标签、统计、简介、原卡开场白；
  - 右栏：开始新故事的 5 个步骤；
  - 两栏各自滚动；
  - 右栏底部浮着一条摘要栏（已选项胶囊加“开始故事”按钮），圆角 34，带投影；
  - 第 1 步的名字建议排在输入框右侧（第 2 步的身份图块已去掉，只有输入框）。
- **剧本详情中屏：** 单栏，宽 640，居中。

### 7. 设置（T13–T15）

- **宽屏两栏：**
  - 左栏宽 340，就是现在的设置首页（导演模型卡片、配置、其他、版本号）；
  - 右栏是详情区：从 x = 488 到右边留 16，上下各留 16，圆角 32，底色 `bg2`，里面的卡片是白色；
  - 左栏里当前打开的项显示为白底加 2px 蓝色内描边；
  - 右栏内部再往下一层时（密钥列表 → 密钥详情），顶部显示“‹ 上一层名字”胶囊，左栏不动；
  - 默认打开导演模型；没有导演模型时打开密钥与端点。
  - 详情区够宽时可以排两列卡片，例如密钥详情的“选择模型”和“测试结果”并排。
- **建议实现方式：** 把 `app/settings/*.tsx` 和 `app/dev/probe.tsx` 的页面主体抽成组件，既能作为路由页面（窄屏、中屏），也能嵌进右栏（宽屏）。右栏的层级用本地状态维护一个小栈。窗口从宽屏缩到中屏时，回到设置首页即可，不要求保留右栏位置。
- **中屏：** 单栏，宽 640，居中，逐层进入，和手机一样。
- **外观：** 中屏和宽屏都是居中对话框（T15）。顺带建议把“跟随系统”的说明从“随手机的深色模式切换”改成“随系统的深色模式切换”，平板上也说得通。

### 8. 登录与注册（T01、T02）

- **宽屏：** 左右分栏。
  - 左侧是一块 `bg2` 圆角 32 的插画区：Logo、几何插画、一句介绍，插画用 `react-native-svg` 照 `source/TabletAuth.dc.html` 画；
  - 右侧是表单，宽 400，在右半边居中，服务器入口贴在右半边底部。
- **中屏：** 表单宽 440，居中，服务器入口贴底。服务器选择是居中对话框。

## 验证清单

- iPad 模拟器：竖屏、横屏，分屏 1/3、1/2、2/3，台前调度下随意拖动窗口大小。每种宽度下都没有横向溢出，没有内容被导航栏或面板遮住。
- 13 寸 iPad 竖屏（1032）：应是宽屏布局，世界状态用滑出而不是停靠。
- 横屏打开阅读页，展开世界状态后旋转到竖屏：停靠面板变成滑出面板，阅读状态和草稿不丢。
- 手机上的布局和行为与之前完全一致，包括锁定竖屏。
- 深色模式下每个平板画面都检查一遍；T04、T08 是深色参考。
