电脑上的 BetterTavern 和手机、平板用同一套颜色、圆角、字体和组件。多出来的只有三样：左边一条常驻的侧栏，在故事之间来回；鼠标和键盘——悬停、焦点、右键、快捷键；以及把角色卡直接拖进窗口。正文仍然是一本书的宽度。

侧栏（≥ 1280）

一块浮起的灰色面板，和世界面板左右呼应。上面是 Logo 和收起按钮，然后是故事、剧本、设置三个入口，中间是最近的故事，点一下直接打开阅读页，不用先回到故事列表。最下面是账户，点开就是设置里的账户页。

导航条（900–1279，或手动收起）

就是平板横屏的那条导航条，宽 76。比平板多两样：Logo 下面的“展开侧栏”按钮，以及最近四个故事的封面（正在写的带蓝点，悬停显示书名）。窄于 1280 时点“展开”，侧栏盖在内容上，带遮罩，点外面收回。

收起和展开

≥ 1280 时侧栏默认展开，用户收起后记在浏览器里，下次打开还是收起的。快捷键 [ 切换。阅读页里打开世界、放不下三栏时，侧栏会临时收成导航条，关掉世界再展开。

没有返回栏

侧栏一直在，所以一级页、阅读页都不需要返回按钮。剧本详情的封面上保留返回（回剧本库）；设置右栏往下钻一层时，顶上仍是“‹ 上一层”的胶囊。

Reading

阅读页

正文还是一本书的宽度。多出来的地方，左边给故事之间的切换，右边给世界。

1440 × 900 · 侧栏展开、世界停靠时，阅读区 748 宽
世界停靠：窗口 − 左边导航 ≥ 1100

阅读栏 640 + 两侧各 24，加上世界 400 和边距，正好 1100——和平板的停靠门槛同一个数。停靠时不加遮罩，阅读栏在剩下的宽度里居中，底栏的“世界”按钮显示为选中（墨色），再点一次收起。

侧栏让位：1188 ≤ 窗口 < 1380

侧栏展开时放不下三栏，但收成导航条就放得下：打开世界时侧栏临时收成导航条，关掉世界再展开回来（W07）。

其余：从右侧滑出

宽 400，离窗口上、下、右各 12，盖在正文上，带遮罩；点遮罩、按 Esc 或右上角 × 关闭（W11）。

底栏贴底，内容 672

底部操作栏铺满阅读区、顶上一条细线，内容宽 672，和阅读栏同一条中线。选项接在正文末尾，跟着正文滚动；宽屏两列，奇数个时最后一项占满一行。

悬停

灰块深一档（bg2 → bg3），墨色主按钮浅一档，白卡加一层浮起阴影。卡片和列表行悬停时右上角出现“…”。只在有鼠标的设备上生效（@media (hover: hover)）。

按下

和手机一样缩到 0.98（小按钮 0.97），颜色停在悬停那一档。选项按下就是选中：浅蓝底加 2px 蓝色内描边，字母键变蓝。

键盘焦点

2px 蓝色焦点环，和元素隔开 2px 的底色，只在键盘操作时出现（:focus-visible），鼠标点击不出现。输入框聚焦用 2px 内描边，和手机一样。

光标与提示

能点的东西用手形光标；正文是文字光标，可以选中复制。图标按钮悬停 500ms 出墨色提示胶囊，带快捷键。

单键快捷键的规矩

字母、/、[ 和 ? 只在焦点不在输入框、也没有按住 ⌘ / Ctrl / Alt 时生效，不和浏览器、输入法抢键。用读屏或语音输入的人可以在快捷键对话框里一键关掉（W12）。对话框打开时，焦点留在对话框里，关掉后回到打开它的那个按钮。删除类确认框的焦点默认在“取消”上。

Browser

浏览器里的细节

网页和 App 不同的地方：链接、右键、滚动、拖放、字号、标签页。

链接就是链接

故事卡、侧栏里的故事行、剧本卡都用真正的 <a href>：⌘ / Ctrl + 点击、中键在新标签页打开，地址栏的路径和 App 里的路由一样（/play/[id]、/scenario/[id]、/settings/…）。

右键菜单

只在故事卡、侧栏的故事行、剧本卡上换成自己的菜单，第一项是“在新标签页打开”，补上被替换掉的浏览器菜单。正文和输入框保留浏览器自己的右键菜单（复制、拼写检查）。

滚动

只有内容区自己滚，侧栏、世界面板、底栏不动。滚动条用细的浮层样式，悬停时才出现。阅读页离开最新位置时，底栏出现“回到最新”，和手机一样。

拖放导入

剧本库里把 .png / .json 角色卡拖进窗口：内容区盖一层浅蓝色的接收区，松开后逐个导入，进度和结果用提示浮条。在别的页面拖进来也接收，导入完跳到剧本库。

字号

阅读设置里的“跟随系统字体大小”在浏览器里改成“跟随浏览器字号”：正文按 1rem 的比例缩放（17.5 → 1.09375rem），用户在浏览器里调大字号时一起变大。

标签页标题

阅读页是“雨夜渡口 · BetterTavern”，生成中在前面加一个“●”，切到别的标签页也能看见故事还在写。
