# BetterTavern 电脑 Web 端 UI（柔和圆角版）

这一份是 BetterTavern 在电脑浏览器里的设计稿。颜色、圆角、字体和组件全部沿用上一级目录的手机设计稿（`docs/design/ui/`）和平板设计稿（`docs/design/ui/tablet/`）。本目录只规定三件事：

1. **窗口 ≥ 1280 时多出来的一档布局。** 左边是常驻的侧栏，阅读页是“侧栏 + 正文 + 世界”三栏。
2. **鼠标和键盘。** 包括悬停、键盘焦点、右键菜单、提示和快捷键。
3. **只有浏览器里才有的细节。** 包括链接、拖放导入、下载文件、标签页标题和字号。

窗口窄于 1280 时，沿用平板和手机的规则。唯一的例外在阅读页，见“断点”一节。

## 怎么实现（建议）

`web-spa` 分支上那一版网页端已经弃用。不要在它上面改，也不要合并或照搬它的代码，从 `m1` 新开分支重写。

建议新建 `apps/web`，只用浏览器的 DOM 和 CSS，不用 react-native-web。理由：

- **这套稿子依赖的都是浏览器原生的东西：**
  - 真正的链接（⌘ / Ctrl + 点击在新标签页打开）；
  - 表单自动填充；
  - `:focus-visible` 和 `@media (hover: hover)`；
  - 右键菜单、拖放；
  - 选中复制、滚动条、`rem` 字号、标签页标题。

  这些用 DOM 和 CSS 写最直接。
- **业务逻辑不用重写：** App 里的纯 TypeScript 部分可以直接共用，网页端只写界面层和平台替代。

| 层 | 建议 |
| --- | --- |
| 构建 | Vite + TypeScript（strict） |
| 界面 | React 19，DOM + CSS；颜色全部是 CSS 变量（`tokens.css`） |
| 路由 | react-router，地址和 App 的路由一一对应：`/login`、`/register`、`/playthroughs`、`/library`、`/scenario/:id`、`/play/:id`、`/settings`、`/settings/models`、`/settings/model/:id`、`/settings/account`、`/dev/probe` |
| 共用 | 经路径别名直接引用 `apps/mobile/src` 里的纯 TypeScript，见下面的列表 |

共用的代码：

- 接口客户端与类型；
- SSE 与续传；
- 会话与令牌刷新；
- 回合状态机与 `PlaySession`；
- 开局表单规则；
- 窗口格子、关系图布局；
- 最近服务器、探针；
- 色板与主题表、格式化；
- 平板的 `layout.ts`。

共用的规矩：

- **只引用不依赖 React Native、Expo 的文件。** 有些数据和界面写在同一个组件里，比如图标路径、几何封面的图形。先在 `apps/mobile` 里把数据拆成纯数据文件，手机端行为不变，再两边一起用。
- **测试分工。** 共用的逻辑已经有手机端的测试（`node --test`）；网页端只测自己的纯逻辑：`layout.ts`、存储、快捷键判断。

平台替代：

| App 里 | 网页端 |
| --- | --- |
| `expo-secure-store` 存令牌、服务器地址、界面偏好 | `localStorage`，键名相同；隐私模式下存不进去时当作没存过。令牌放在 localStorage，同一网址下的脚本能读到，这是取舍；要更严就得让服务端改成下发 httpOnly Cookie，先不改 |
| `expo/fetch` 读流 | 浏览器 `fetch` 的 `ReadableStream`，接到同一个 SSE 客户端（它按 `FetchLike` 注入） |
| App 回到前台时重连、刷新 | 标签页重新可见（`visibilitychange`）、窗口回到前台时重连和刷新 |
| 下拉刷新 | 回到标签页时自动刷新 |
| 左滑、长按出菜单 | 悬停出现“…”，右键也能打开同一个菜单 |
| `expo-document-picker` + `expo-file-system` 的 `File` | `<input type="file">` 和拖放拿到的浏览器 `File` |
| `Share.share` 导出诊断日志 | 下载 `.json` 文件 |
| 键盘弹起时操作栏跟着上移（`useKeyboardLift`） | 不需要 |
| 字号“跟随系统”（动态字体） | “跟随浏览器字号”（`rem`） |
| 封面图片带令牌下载 | `fetch` 带令牌，转成 `blob:` 地址显示，按“服务器 + 图片 ID”缓存 |

运行：

- **本机开发。** 开发和预览服务器把 `/v1`、`/health`、`/ready` 代理到后端（默认 `http://localhost:8000`），本机不用配跨域。
- **换服务器。** 登录页底部可以换成别的服务器。那台服务器要在 `CORS_ORIGINS` 里加上网页的地址（服务端已经支持这个配置）。

本目录两个文件的用法：

- `layout.ts` 放进网页端的 `theme/`，平板的函数从 `apps/mobile/src/theme/layout.ts` 引入。
- `tokens.css` 的调色板变量名，是 App 色板字段名转成短横线写法（`accBg` → `--acc-bg`）。建议主题组件从共用色板把当前主题写到 `:root` 上，再加上这里新增的部分：悬停色、表面、布局尺寸、浏览器全局样式。

## 断点：只看窗口宽度

| 窗口宽度 | 导航 | 页面 |
| --- | --- | --- |
| < 600 | 手机：底部胶囊 Tab 栏 | 手机设计稿原样 |
| 600–899 | 平板中屏：底部胶囊，宽 392 居中 | 居中单栏，最宽 640 |
| 900–1279 | 导航条，宽 76。就是平板宽屏那条，多一个“展开侧栏”按钮和最近四个故事的封面 | 设置、剧本详情两栏；故事三列；剧本按宽度分列 |
| ≥ 1280 | 侧栏，宽 268。用户收起后是导航条 | 同上；故事、剧本列表的内容最宽 1200，超出后居中 |

- 用 `layout.ts` 的 `navMode(width, collapsed)` 判断。
  - `collapsed` 是用户自己收起了侧栏，存在浏览器里，下次打开保持。
  - < 900 时它返回 `"tabbar"`，这时交给平板的 `sizeClass()` 和手机布局处理。
- **和原生平板的区别。** 在 Web 上，阅读页、剧本详情、设置子页都保留左边的侧栏或导航条，所以：
  - 阅读页不显示返回按钮；
  - 剧本详情封面上的返回保留，回到剧本库。

  原生平板仍按平板 README，进入二级页时隐藏导航栏。
- 拖动窗口改变宽度时，布局即时切换。草稿、滚动位置、打开着的世界面板都不能丢。

## 实现要点

### 1. 侧栏与导航条

**侧栏（≥ 1280）**

- **外形：**
  - 离窗口左、上、下各 12，宽 268，圆角 28，底色 `bg2`；
  - 里面用“灰底白卡”的表面，和平板的世界面板相同（`PanelSurfaces`；CSS 里是 `.surface-panel`）。
- **从上到下：**
  1. **顶部。** Logo 26，“BetterTavern”16/700，右边是收起按钮：36 的透明圆按钮，用侧栏图标。
  2. **导航。** 故事、剧本、设置三项。
     - 每项是高 44 的胶囊，图标 20，文字 15；
     - 选中项墨色底、反白，悬停 `bg3`。
  3. **最近的故事。** 小标题“最近的故事”，右边是数量（等宽）。
     - 按“今天 / 本周 / 更早”分组，组名是等宽 11.5 的小字。
     - 每行高 54，圆角 18：封面 36，标题 14/500，下面一行是状态。
     - 状态和故事卡片同一套规则（`StoryCards.tsx` 的 `Status`）：
       - 平时显示等宽的相对时间；
       - “正在写开场 / 正在写下一段”是蓝字带圆点；
       - “开场还没有写好”是琥珀色。
     - 当前打开的故事：白底加 `shadowLift`。
     - 悬停：`bg3`，右侧出现 30 的白色“…”按钮，菜单同故事卡片（见“浮层”）。
     - 数据就是故事列表接口。这一块单独滚动，不限条数。
  4. **账户。** 在最底下：头像 32、昵称、邮箱（等宽），点开是设置里的账户页。
- **整条侧栏都是链接：** 用 `<a href>`，见“浏览器里的细节”。

**导航条（900–1279，或用户收起侧栏后）**

- 就是平板宽屏那条：宽 76，选中项 60×64、圆角 30。位置改成离窗口 12（平板是左 16、顶 32），高度拉满。
- 从上到下依次是：
  - Logo 28；
  - “展开侧栏”按钮；
  - 故事、剧本、设置；
  - 一条短分隔线；
  - 最近四个故事的封面：52 的圆角块。当前故事白底浮起，正在写的右上角有一个蓝点，悬停出提示，显示书名；
  - 底部是头像。
- 窄于 1280 时点“展开”，侧栏盖在内容上，带遮罩。点遮罩、按 Esc 或者点了侧栏里的一项都会收回（`sidebarOverlays(width)`）。≥ 1280 时侧栏占位，内容让开。
- 快捷键 `[` 展开或收起侧栏。

### 2. 栏宽与位置（`layout.ts`）

| 用途 | 宽度 |
| --- | --- |
| 侧栏 / 导航条 | 268 / 76，离窗口边 12 |
| 一级页内容离侧栏、离窗口右边 | 40 |
| 故事、剧本列表的内容最宽 | 1200，超出后居中 |
| 阅读栏 | 640（同平板） |
| 阅读页底部操作栏的内容 | 672（同平板） |
| 世界面板 | 400，离窗口右、上、下各 12 |
| 设置左栏 / 剧本详情左栏 | 340 / 420 |
| 设置右栏宽于这个值时详情分两栏 | 720 |
| 居中对话框 / 键盘快捷键对话框 | 480 / 600 |
| 贴着按钮的菜单 / 右键菜单 | 340 / 240 |
| 提示浮条 | ≤ 480 |

几个位置的算法：

- **一级页的内容区：** `pageFrame(width, nav)`。1440 宽、侧栏展开时，内容从 x = 320 开始，宽 1080。
- **阅读区：** `readingArea(width, nav, world)`，阅读栏和底部操作栏都在这里面居中：用平板 `layout.ts` 的 `readableColumn(area.width)`、`actionPanelFrame(area.width)` 算出位置，再加上 `area.left`。
- **设置两栏：** `settingsFrame(width, nav)`。1440 宽时，左栏从 320 开始，右栏从 684 开始、宽 744，分两栏。

### 3. 浮层

- **居中对话框。** 用于服务器、外观、重命名、确认删除、揭示秘密、删除账户确认，以及键盘快捷键。
  - 外形：宽 ≤ 480（快捷键 600），圆角 32，底色 `sheet`，阴影 `shadowFloat`，后面是遮罩 `scrim`。
  - 关闭：Esc，或点遮罩。
  - 焦点：打开后焦点移进对话框，Tab 在对话框里循环；关闭后焦点回到打开它的按钮。
  - 默认焦点：删除类和揭示秘密的确认框落在“取消”上（W10），其他对话框落在第一个输入框或主按钮上。
- **贴着按钮的菜单。** 阅读页的“更多”。宽 340，用平板的 `popoverFrame` 定位，不加遮罩，点外面或按 Esc 关闭。打开时“更多”按钮显示为选中（墨色）。
- **右键菜单。**
  - 出现在哪些地方：故事卡、侧栏里的故事行、导航条上的封面、剧本卡、剧本列表行。
  - 外形：宽 240，圆角 24，底色 `sheet`，阴影 `shadowFloat`，菜单项高 44。
  - 位置：左上角在鼠标处，放不下时往左、往上翻（`contextMenuFrame`）。
  - 菜单项：“在新标签页打开”“重命名”，一条分隔线，然后是“删除”（红色）。删除仍然先弹确认框，文案同 App。
  - 这些卡片悬停时，右上角出现 36 的白色“…”按钮，点它弹出同一个菜单，贴着按钮出现。键盘用户用 Tab 走到卡片上，按 Shift + F10 或菜单键打开。
- **提示（tooltip）。**
  - 只给图标按钮和导航条上的封面用：世界、更多、回到最新、收起侧栏、展开侧栏、编辑、关闭等。
  - 悬停 500ms 出现，键盘焦点到达时也出现。
  - 外形：墨色胶囊，高 32，字 12.5；有快捷键时右边带键帽（W07）。
  - 默认在元素上方 8，上面放不下就放到下方（`tooltipFrame`）。
- **提示浮条。** 在内容区底部居中，宽 ≤ 480，4 秒后消失；鼠标停在浮条上时不消失。

### 4. 鼠标：悬停、按下、键盘焦点（布局系统里的状态表）

颜色只在已有的几档灰之间走，不新增颜色。

| 状态 | 规则 |
| --- | --- |
| 悬停 | 灰块深一档（`bg2` → `bg3`，浅色、夜间都是）；墨色主按钮浅一档（`#33332F`，夜间 `#FFFFFF`）；白卡不换色，加一层 `shadowLift`；卡片和列表行出现“…”。只在 `@media (hover: hover) and (pointer: fine)` 下生效，触屏的平板浏览器不会停在悬停色上 |
| 按下 | 和 App 一样缩到 0.98（小按钮 0.97），颜色停在悬停那一档。选项按下即选中：浅蓝底、2px 蓝色内描边，字母圆变蓝 |
| 键盘焦点 | 2px 蓝色焦点环，和元素之间隔 2px，只在键盘操作时出现（`:focus-visible`）。输入框聚焦仍是 2px 内描边，和 App 一样 |
| 不可用 | 透明度 0.32，和 App 一样；不响应悬停 |
| 选中 | 侧栏导航墨色；当前故事白底浮起；设置左栏当前项白底 + 2px 蓝色内描边 |

这些状态写在共用的按钮、选项、列表行组件和它们的样式里，不要逐个页面写：

- 悬停用 `:hover`，放在 `@media (hover: hover) and (pointer: fine)` 里；
- 按下用 `:active`；
- 键盘焦点用 `:focus-visible`。

`tokens.css` 最后一段有现成的写法。

光标：能点的东西用手形光标；正文是文字光标，可以选中复制；按钮和导航的文字不可选。

### 5. 键盘快捷键（W12）

快捷键表在 `layout.ts` 的 `SHORTCUTS`，对话框和键帽都从这里取。

| 键 | 作用 | 生效范围 |
| --- | --- | --- |
| A / B / C / D | 选一个选项 | 阅读页，有选项时 |
| / | 自己写（展开底栏的输入框并聚焦） | 阅读页 |
| Enter / Shift + Enter | 发送 / 换行 | 输入框里 |
| Esc | 收起输入框，草稿留着；关闭菜单、对话框和滑出的面板 | 任何地方，先关最上面一层 |
| End | 回到最新 | 阅读页 |
| W | 打开或收起世界状态 | 阅读页 |
| [ | 展开或收起侧栏 | ≥ 900 |
| ? | 键盘快捷键一览 | 任何地方 |

单键快捷键的规矩：

- **什么时候生效。** 字母、`/`、`[`、`?` 只在下面条件都满足时生效（`acceptsSingleKey`）：
  - 焦点不在输入框、文本框或 contenteditable 里；
  - 没有按住 ⌘、Ctrl 或 Alt；
  - 没有在用输入法组字。
- **可以关掉。** 用读屏或语音输入的人可能需要关掉这些单键快捷键。开关在快捷键对话框顶上，默认打开，存在浏览器里。
- **Enter 发送时注意输入法。** 输入法组字时按的 Enter 是确认候选词，不能发送。判断 `event.isComposing`，Safari 上还要看 `keyCode === 229`。

### 11. 浏览器里的细节

- **链接就是链接。**
  - 故事卡、侧栏里的故事行、剧本卡、设置左栏的项都用 `<a href>`。
  - ⌘ / Ctrl + 点击、中键会在新标签页打开。
  - 浏览器的前进、后退和 App 的路由一致。
- **右键菜单。**
  - 只在上面列出的卡片和行上换成自己的菜单，第一项“在新标签页打开”，补上被替换掉的浏览器菜单。
  - 正文和输入框保留浏览器自己的右键菜单（复制、拼写检查）。
- **滚动。**
  - 只有内容区自己滚动；侧栏、世界面板、底栏、设置左栏都不动。
  - 滚动条用 `tokens.css` 里的细样式。
  - 阅读页的跟随规则同 App。
- **字号。** 阅读设置“跟随浏览器字号”时，正文用 `rem`；固定字号时用 `px`，档位同 App（15–24）。
- **深色模式。** “跟随系统”就是 `prefers-color-scheme`。`index.html` 里放一小段脚本，在页面脚本加载前按外观设置铺好底色、设好 `data-scheme`，深色下打开不闪白。
- **离开页面。** 底栏里有没发送的草稿时，草稿存在浏览器里（每个故事一份），刷新、关掉标签页都不丢，不弹“确定离开吗”。
- **最小宽度。** 页面在 320 宽以上都能用。窄到 600 以下就是手机布局，不出现横向滚动。
