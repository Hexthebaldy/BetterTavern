# BetterTavern 移动端 UI（第一版正式界面）

这是移动端（`apps/mobile`）第一版的正式界面设计。手机的画板在本目录，平板在 `tablet/`，电脑浏览器在 `web/`，标志和 App 图标在 `../logo/`。

设计方向是“白 / 柔线 / 大圆角”：
- 纯白页面，内容放在浅灰圆角卡片里；
- 按钮、标签、分段控件都是胶囊形；
- 分区靠灰卡和留白，不靠黑线；
- 图标描边圆头圆角；
- Tab 栏离开屏幕边缘，做成带柔和投影的浮层。

**电脑 Web 端：** 侧栏、三栏阅读页、鼠标和键盘的规则和画面见 `web/`（先读 `web/README.md`）。同样沿用本目录的视觉规则，窄于 1280 的窗口沿用平板和手机的布局。

## 视觉规则（实现时必须遵守）

### 圆角

规则是“容器越大，圆角越大”。嵌套时，内层圆角 = 外层圆角 − 内边距。

| 用途 | 圆角 |
| --- | --- |
| 标签、小徽标 | 10 |
| 输入框 | 14 |
| 封面、头像方块 | 16 |
| 卡片、提示条 | 20 |
| 列表卡片、阅读页选项 | 24 |
| 分组卡 | 28 |
| 底部面板、对话框 | 32 |
| 按钮、标签、分段控件、Tab 栏、开关 | 全圆（高度 / 2） |

不要出现 2–8 这种小圆角，小圆角会让界面看起来廉价。

### 层级和状态

- **层级靠“灰卡放在白底上”表达。**
  - 页面是 `bg`，卡片和输入框是 `bg2`；
  - 卡片里面再嵌一层时用 `bg3`，或者白色的 `card`；
  - 不画外框；`line` 只用来分隔卡片内部的行。
- **阴影只给浮起来的东西：** Tab 栏、底部面板与对话框、提示浮条、弹出菜单（见 `tokens.ts` 的 `shadow`）。其他地方一律不用阴影。
- **状态靠换底色，不靠换线：**
  - 未选中：浅灰底；
  - 选中：黑底（`ink`），或浅蓝底加 2px 蓝色内描边；
  - 聚焦：一圈 2px 的 `acc`；
  - 按下：缩到 97%，底色加深一档；
  - 禁用：不透明度 0.3。
- **语义色：**
  - “我”、当前项、流式光标用蓝色 `acc`；
  - 红 / 绿 / 琥珀只表示错误 / 可用 / 警告，并且一定配图标，不能只靠颜色区分。

### 字体

- 界面用系统黑体，不打包字体文件。
- 一级页大标题 32/40、字重 700，标题下不画线。
- 页面和面板标题 20/28、字重 600。
- 等宽字（时间、计数、Key 尾号、上下文窗口）用 IBM Plex Mono（`@expo-google-fonts/ibm-plex-mono`）。
- 故事正文用思源宋体（Noto Serif SC）的子集，在阅读设置里可以切换成黑体。

### 图标

- 24 栅格，描边 1.75，`strokeLinecap="round"`、`strokeLinejoin="round"`。
- 用 `react-native-svg` 实现，路径直接从 `source/Main.dc.html` 的图标区复制。

### 尺寸与导航

- **按钮：** 高 52 的胶囊。推进流程的主按钮文字靠左，右侧嵌一个 36 的半透明圆，里面放箭头。
- **触控目标** 至少 44。
- **Tab 栏：** 一条浮起的胶囊。
  - 尺寸：高 64，左右各 20，离底 28，再加安全区；
  - 选中项展开成高 48 的黑色小胶囊，图标和文字横排；
  - 未选中项是图标在上、文字在下；
  - 列表内容要在底部留出足够空间，不被 Tab 栏遮住。
- **导航按钮：** 40 的灰色圆底，热区仍是 44。
- **一级页：** 标题右侧放一个计数胶囊，或者一个圆形主操作按钮。
- **提示浮条（Toast）：** 墨色胶囊，贴着 Tab 栏上方浮起，3 秒后自动消失。
- **对话框和底部面板：**
  - 底部面板顶部有一根 40×5 的拖拽条，下拉或点遮罩关闭；
  - 面板四周离屏幕边缘 8。

### 深色模式

每个 token 都有深色值（见 `tokens.ts`）。外观可以跟随系统，也可以在“设置 → 外观”里固定浅色或夜间。深色下浮层用 `card`（#2A2A2F），底部面板和对话框用 `sheet`（#1F1F23），叙述正文用 `narr`。

## 阅读页要点

- **叙述正文** 用宋体 17.5/31，左右页边距 24，段落之间空 16，不做首行缩进，两端对齐。
- **“我的行动”** 和叙述是同一种字（跟着阅读设置的字体和字号），颜色浅一档（`ink2`），左边一道 3 宽的 `line2` 竖线，字往里缩 14。
  - 它不是卡片，也不是聊天气泡，读起来是故事的一部分；
  - 读屏时在前面加隐藏文字“我的行动：”。
- **选项** 接在最新一段后面，跟着正文滚动，不挡正文。
  - 圆角 24 的灰卡，左边一个 32 的圆形字母键（A / B）；
  - 按下后整张卡变成 `accBg` 加 2px 蓝色内描边，字母键变成蓝底，并缩到 98%；
  - 开场没写时这里是“开始故事”；失败时是一张 `errBg` 的错误卡片，下面并排“换个行动”和“重试”，没写完的正文变灰，末尾加一个“中断”小标签。
- **底部操作栏** 贴着屏幕底边，页面底色，顶上一条细线，iPhone 上连安全区约 80。
  - 左边“世界”（罗盘），右边“更多”，都是 44 的灰色圆按钮；平板上世界状态停靠时，世界按钮变成墨色；
  - 中间一格按状态换：
    - 空闲：“自己写…”，样子像一个输入框，有草稿时显示草稿；点一下原地展开成输入框，跟着键盘浮起，发送或收起后缩回来；
    - 生成中：蓝色小圆点加一句状态（正在发送 / 正在构思 / 世界还在更新 / 正在写下一段），右边是胶囊形的“停止”；
    - 断线重连、等结果：圆点和文字变成琥珀色；
    - 同步中：锁和“同步完成前暂时不能行动”。
  - 生成状态只在操作栏里显示，正文里不重复。
- **流式光标** 是 3×20 的蓝色圆头竖条，不闪烁。新字只追加在最后一个文本节点，已经写完的回合固定渲染。
- **导航栏** 只有返回和居中的标题。

## 交互规则

原则：读的时候不打扰，动手的地方在拇指下。顶部只放返回，所有回合操作都在屏幕下方。

### 滚动跟随

- 停在底部时，新字出现就贴着底部跟随。
- 只认手指：内容变长时程序滚动产生的事件不算“翻走”，只有手指拖动和惯性滚动才会关掉跟随。
- 往上翻离开底部超过 80 时暂停跟随，操作栏中间那一格的右端滑出一个下箭头圆按钮（灰底，和世界、更多一样），“自己写…”跟着变窄；生成中箭头带一个蓝点，表示下面有新内容。点它回到底部并恢复跟随，箭头收起。
- 打开故事就停在最新一段；往上翻到顶是一页书名页：封面、标题，以及“我是谁”。
- 动态字体与读屏：正文跟随系统字号（15–24），“更多”里也可以单独调阅读字号、在宋体和黑体之间切换。每段写完后整段朗读，不逐字播报。

### 提交与输入

- **防重复提交：** 点下选项后，那一句立刻作为“我的行动”出现在正文里，直到服务端确认；网络错误自动重试时不会重复提交。
- **没有选项的回合** 直接展开输入框，不能收起。
- **键盘：** 输入框跟着键盘上移；收起不清空草稿；剩 200 字以内时显示剩余字数。
- **Android 返回键：** 面板开着时先关面板，否则离开阅读页。离开阅读页不会中断生成，回来时接上。

### 删除

- 入口：故事、剧本列表左滑，或者长按；剧本、模型、账户的删除另外放在详情页最底部，用红色按钮。
- 长按弹出的菜单和左滑给出同样的选项，照顾不习惯左滑的人和读屏用户。
- 左滑到底也不会直接删除：每次都要经过确认框（红色图标，写清后果），确认后墨色浮条提示“已删除”。

### 导入角色卡

- 点剧本库右上角的“+”（平板宽屏是“导入角色卡”胶囊）→ 系统文件选择器，只接受 `.png`、`.json`，本地先检查不超过 16 MB。
- 上传中：网格里出现一个“正在导入”的格子，带转圈。
- 结果：
  - 成功：直接进入剧本详情；
  - 之前导入过：墨色浮条“之前已经导入过了”，带“打开”；
  - 失败：页面顶上出红色提示条，说明原因，留在剧本库。

### 选，而不是写

能用选择控件的地方不让用户打字。这些控件最终仍拼成原来的字段发给后端，接口不需要改：

| 位置 | 原来 | 现在 | 需要什么 |
| --- | --- | --- | --- |
| 登录、注册 | 服务器地址输入框 | 面板：最近用过的服务器单选 + “输入新地址” | 在本地记住最近用过的地址 |
| 开始新故事 01 | 角色名输入框 | 输入框 + 名字建议标签 + 随机按钮 | 客户端内置一组名字 |
| 开始新故事 02 | “这个角色是谁”多行输入 | 身份图块（选中后自动填一句底稿）+ 可编辑的多行框 | 内置身份和对应底稿 |
| 开始新故事 03 | 短 / 适中 / 长 | 用行数图示的三格分段 | 无 |
| 开始新故事 04 | 文风输入框 | 多选标签 + 自定义，拼成文本（≤200 字） | 内置标签列表 |
| 开始新故事 05 | “不想看到”输入框 | 勾选清单 + 其他，拼成文本（≤300 字） | 内置清单 |
| 添加模型 | 服务商分段 + 端点输入 + 模型名输入 | 服务商图块 + “使用官方地址”勾选；填好 Key 后自动获取模型列表单选，搜索框兼做手动输入 | 无 |
| 连接测试 | 时长输入框 | 30s / 60s / 2m / 5m 分段 | 无 |
| 阅读页 | 无 | “更多”菜单里的阅读设置 | 本地保存字体和字号 |
| 剧本库 | 列表 | 网格 / 列表切换；没有图片的角色卡用几何封面 | 按卡片 ID 从 5 种母题里确定性地选一种（见 `Main.png` 的“几何封面”） |

### 后端能力的入口

- **世界状态：** 人物与地点、关系图、事实三页；主角不知道的秘密默认隐藏，揭示前要确认（琥珀色锁 → 确认框“会剧透” → 标为“秘密 · 已揭示”）。
- **重命名：** 故事和剧本都可以重命名，入口是列表左滑或长按，以及阅读页、剧本详情的“更多”菜单。
- **编辑模型：** 改备注名、模型名和端点，入口是模型详情标题旁的铅笔；更换 Key 在详情页底部。
- **导演模型：** 在模型列表或模型详情里设为导演；取消导演在模型详情页底部。

## 不要照抄的部分

- **示例数据都不是真实的：** 故事和角色文本、模型列表、测试耗时、“每轮输出 8K”、窗口占比、版本号和服务器地址。
- **画板外壳：** `.tag` 编号胶囊、多屏并排的布局、手机外框的圆角和描边、键盘占位区、截图里的状态栏留白。
- **等宽字体：** 截图里如果显示成系统等宽字体，是截图环境的问题，实际应该用 IBM Plex Mono。
- **少数深色值：** `Main.png` 色板上个别深色值和源码 CSS 有出入（例如深色的“线”）。以 `tokens.ts` 为准。
