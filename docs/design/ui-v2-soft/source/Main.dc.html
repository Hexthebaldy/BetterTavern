BetterTavern · Design Language 02 · Soft

白，柔线，
大圆角。

和直角版用同一套颜色、字体和结构，只换形状语言：所有容器都是大圆角，按钮和标签是胶囊；分区不再靠黑线，而是靠浅灰圆角卡片和留白；图标改成圆头圆角的描边。目的是让人放松地读很久，而不是像一份规格说明。

01
白底灰卡

页面是纯白，内容放在 #F5F5F2 的圆角卡片里。层级靠“卡片套在白底上”来表达，不用线。

02
胶囊与大圆角

按钮、标签、分段控件做成胶囊；输入框圆角 14，卡片 20–28，底部面板 32。头像和封面是 16 的圆角方块。

03
柔线

线条只剩极浅的 #EEEEEA，作用是分隔卡片里的行，不再画外框。描边图标 1.75 粗、圆头圆角，接近手写。

04
浮起，而不是贴底

Tab 栏和阅读页的行动栏都离开屏幕边缘，成为带柔和投影的浮层。这是整套里唯一使用阴影的地方。
