# BetterTavern 移动端 UI v2 · 柔和圆角版（当前采用）

这一份取代 `docs/design/ui-v2/`（直角版）作为移动端（`apps/mobile`）的视觉参考。两版的页面结构、信息、状态和交互完全相同，只是形状语言不同。

设计方向是“白 / 柔线 / 大圆角”：
- 纯白页面，内容放在浅灰圆角卡片里；
- 按钮、标签、分段控件都是胶囊形；
- 分区靠灰卡和留白，不靠黑线；
- 图标描边圆头圆角；
- Tab 栏和阅读页行动栏离开屏幕边缘，做成带柔和投影的浮层。

**和直角版的分工：**
- 以本目录为准的：形状、颜色、间距、组件外观。
- 仍然看 `../ui-v2/` 的：
  - 行为规则（`../ui-v2/png/Interactions.png`，以及 `../ui-v2/README.md` 的“新增或改动的交互”一节）；
  - 闪屏的布局（本版没有单独画闪屏，按本版 token 套用即可）。
- 如果直角版已经实现了某个页面：保留结构和逻辑，只换 token 和组件样式。

## 视觉规则（实现时必须遵守）

### 圆角

规则是“容器越大，圆角越大”。嵌套时，内层圆角 = 外层圆角 − 内边距。

| 用途 | 圆角 |
| --- | --- |
| 标签、小徽标 | 10 |
| 输入框 | 14 |
| 封面、头像方块 | 16 |
| 卡片、提示条、“我的行动”卡片 | 20 |
| 列表卡片、阅读页选项 | 24 |
| 分组卡 | 28 |
| 底部面板 | 32 |
| 阅读页浮动行动面板（四周留 8） | 36 |
| 按钮、标签、分段控件、Tab 栏、开关 | 全圆（高度 / 2） |

不要出现 2–8 这种小圆角。小圆角会让界面看起来廉价，这正是这次重做要去掉的东西。

### 层级和状态

- **层级靠“灰卡放在白底上”表达。**
  - 页面是 `bg`，卡片和输入框是 `bg2`；
  - 卡片里面再嵌一层时用 `bg3`，或者白色的 `card`；
  - 不画外框；`line` 只用来分隔卡片内部的行。
- **阴影只给浮起来的东西：** Tab 栏、阅读页行动面板、提示浮条、“回到最新”按钮（见 `tokens.ts` 的 `shadow`）。其他地方一律不用阴影。
- **状态靠换底色，不靠换线：**
  - 未选中：浅灰底；
  - 选中：黑底（`ink`），或浅蓝底加 2px 蓝色内描边；
  - 聚焦：一圈 2px 的 `acc`；
  - 按下：缩到 97%，底色加深一档；
  - 禁用：不透明度 0.3。
- **语义色：**
  - “我”、当前项、流式光标用蓝色 `acc`；
  - 红 / 绿 / 琥珀只表示错误 / 可用 / 警告，并且一定配图标，不能只靠颜色区分。

### 字体

- 界面用系统黑体，不打包字体文件。
- 一级页大标题 32/40、字重 700，标题下不画线。
- 页面和面板标题 20/28、字重 600。
- 等宽字（时间、计数、Key 尾号、上下文窗口）用 IBM Plex Mono（`@expo-google-fonts/ibm-plex-mono`）。
- 故事正文用思源宋体（Noto Serif SC）的子集，在阅读设置里可以切换成黑体。

### 图标

- 24 栅格，描边 1.75，`strokeLinecap="round"`、`strokeLinejoin="round"`。
- 用 `react-native-svg` 实现，路径直接从 `source/Main.dc.html` 的图标区复制。
- 注意：直角版的图标是方头尖角，要换掉。

### 尺寸与导航

- **按钮：** 高 52 的胶囊。推进流程的主按钮文字靠左，右侧嵌一个 36 的半透明圆，里面放箭头。
- **触控目标** 至少 44。
- **Tab 栏：** 一条浮起的胶囊。
  - 尺寸：高 64，左右各 20，离底 28，再加安全区；
  - 选中项展开成高 48 的黑色小胶囊，图标和文字横排；
  - 未选中项是图标在上、文字在下；
  - 列表内容要在底部留出足够空间，不被 Tab 栏遮住。
- **导航按钮：** 40 的灰色圆底，热区仍是 44。
- **一级页：** 标题右侧放一个计数胶囊，或者一个圆形主操作按钮。
- **提示浮条（Toast）：** 墨色胶囊，贴着 Tab 栏上方浮起，3 秒后自动消失。
- **对话框和底部面板：**
  - 底部面板顶部有一根 40×5 的拖拽条，下拉或点遮罩关闭；
  - 面板四周离屏幕边缘 8（和阅读页行动面板一致）。

### 深色模式

每个 token 都有深色值（见 `tokens.ts`），跟随系统切换。深色下浮层用 `card`（#2A2A2F），阅读页面板用 `sheet`（#1F1F23），叙述正文用 `narr`。

## 阅读页要点

- **“我的行动”** 是一张缩进的灰色圆角卡片：
  - 外边距左右 16，圆角 20，内边距 14/16；
  - 左边是 26 的 `accBg` 小圆，里面放蓝色转折箭头；
  - 文字用黑体 15/24、字重 500；
  - 它不是聊天气泡：两边都对齐页边距，也没有尖角；
  - 灰卡本身就是回合之间的分隔；
  - 读屏时在前面加隐藏文字“我的行动：”。
- **叙述正文** 用宋体 17.5/31，左右页边距 24，段落之间空 16，不做首行缩进，两端对齐。
- **行动面板** 浮在页面底部：左、右、下各 8，圆角 36，带向上的柔和投影。
  - **空闲：** 选项是圆角 24 的灰卡，左边一个 32 的圆形字母键（A / B）。按下后整张卡变成 `accBg` 加 2px 蓝色内描边，字母键变成蓝底，并缩到 98%。“自己写…”是第三行，透明底、颜色弱一些。
  - **生成中：** 面板顶部的拖拽条（44×5）里有一段 18 宽的蓝色在来回移动，表示正在写，不代表进度。下面一行是蓝色小圆点、“正在写下一段”和胶囊形的“停止”按钮。
  - **断线重连：** 拖拽条和小圆点变成琥珀色，正文上方出现琥珀色的“连接断了，正在重连…”状态胶囊，面板里的文字变成“正在写下一段 · 已写好的不会丢”。
  - **失败：** 面板里是一张 `errBg` 的错误卡片，下面并排两个按钮：“换个行动”和“重试”。没写完的正文变灰，末尾加一个“中断”小标签。
- **流式光标** 是 3×20 的蓝色圆头竖条，不闪烁。新字只追加在最后一个文本节点，已经写完的回合固定渲染。
- **滚动跟随** 沿用现有 `StoryFeed` 的逻辑：只有手指拖动或惯性滚动才会关闭跟随。离开底部超过 80 时，浮出墨色胶囊按钮“回到最新”（高 44，有新内容时带一个蓝点）。
- **导航栏右侧** 有两个灰色圆按钮：
  - 世界状态：罗盘图标，有新变化时右上角带一个蓝色小圆点；
  - “更多”：菜单里有阅读设置（宋体 / 黑体、字号滑杆）、重命名故事和删除故事。

## 不要照抄的部分

- **示例数据都不是真实的：** 故事和角色文本、模型列表、测试耗时、“每轮输出 8K”、窗口占比、版本号和服务器地址。
- **画板外壳：** `.tag` 编号胶囊、多屏并排的布局、手机外框的圆角和描边、键盘占位区、截图里的状态栏留白。
- **等宽字体：** 截图里如果显示成系统等宽字体，是截图环境的问题，实际应该用 IBM Plex Mono。
- **少数深色值：** `Main.png` 色板上个别深色值和源码 CSS 有出入（例如深色的“线”）。以 `tokens.ts` 为准。
