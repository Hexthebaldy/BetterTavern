# BetterTavern 移动端 UI v2 设计稿（参考样本）

这一份是移动端（`apps/mobile`）整套界面重做的设计稿，供实现时对照。设计方向是“白 / 线 / 直角”：白色作底，用 1px 线条分区，所有圆角为 0，黑白两色加一个蓝色强调色，能用选择控件的地方不让用户打字。

在线画布（可缩放、可点 Play 的版本，需要 BetterTavern 作者的账号访问）：
https://claude.ai/artifact/UmtjFbgPZ6Ct2QranXJQNm

## 视觉规则（实现时必须遵守）

- **圆角全部为 0。** 包括按钮、输入框、标签、头像、底部面板、对话框、开关的轨道和滑块。
- **用线分层，不用阴影。** 浅线 `line` 用来分隔列表行；深线 `ink` 标出区块起点（一级页大标题下的 1px 线、分区标题下的 2px 线、底部面板顶边的 2px 线）。阴影只给浮起来的“回到最新”按钮。
- **状态的表达方式：**
  - 选中 = 黑白反转（黑底白字），或 2px 黑色描边；
  - 我的、当前的 = 蓝色 `acc`；
  - 红 / 绿 / 琥珀只表示错误 / 可用 / 警告，并且一定配图标（三角、对勾、虚线方框、叉），不能只靠颜色区分。
- **字体：**
  - 界面用系统黑体（iOS 苹方，Android Noto Sans CJK），不打包；
  - 等宽字（时间、计数、标签、模型名、Key 尾号）用 IBM Plex Mono，可用 `@expo-google-fonts/ibm-plex-mono`；
  - 故事正文用思源宋体（Noto Serif SC）的子集，在阅读设置里可以切换成黑体。
- **图标：** 24 栅格，描边 1.5，`strokeLinecap="square"`、`strokeLinejoin="miter"`。用 `react-native-svg` 实现，路径直接从 `source/Main.dc.html` 的图标区复制。
- **触控目标至少 44pt。** 主按钮高 52pt；推进流程的主按钮文字左对齐、箭头右对齐。
- **深色模式：** 每个 token 都有深色值（见 `tokens.ts`），跟随系统切换。

## 阅读页要点

- “我的行动”是一条通栏浅灰色带（`bg2`，上下各一条 `line`），前面一个蓝色转折箭头，文字用黑体 15/24、字重 500。它同时充当回合之间的分隔，不再需要别的分隔符。读屏时在前面加隐藏文字“我的行动：”。
- 叙述用宋体 17.5/31，左右页边距 24，段落之间空 16，不做首行缩进，两端对齐。
- 选项是整行按钮：左边一个 28×28 的等宽字母键（A / B），右边一个箭头。按下后字母键变成蓝底，整行变成 `accBg`。“自己写…”是第三行，颜色弱一些。
- 行动栏的顶边线就是状态指示：
  - 空闲时是黑色；
  - 生成中有一段蓝线来回扫动（表示正在写，不代表进度）；
  - 重连时变琥珀色；
  - 失败时变红色。
- 流式光标是 2px 宽的蓝色竖条，不闪烁。新字只追加在最后一个文本节点，已经写完的回合固定渲染。
- 滚动跟随沿用现有 `StoryFeed` 的逻辑：只有手指拖动或惯性滚动才会关闭跟随。离开底部超过 80pt 时浮出墨色“回到最新”按钮。
- 导航栏右侧有两个按钮：世界状态（罗盘图标，有新变化时右上角带一个蓝色小方块）和“更多”。“更多”菜单里有阅读设置（宋体 / 黑体、字号）、重命名故事和删除故事。

## 新增或改动的交互（需要客户端补数据或逻辑）

这些控件最终仍拼成原来的字段发给后端，接口不需要改：

| 位置 | 原来 | 现在 | 需要什么 |
| --- | --- | --- | --- |
| 登录、注册 | 服务器地址输入框 | 底部面板：最近用过的服务器单选 + “输入新地址” | 在本地记住最近用过的地址 |
| 开始新故事 01 | 角色名输入框 | 输入框 + 名字建议标签 + 随机按钮 | 客户端内置一组名字 |
| 开始新故事 02 | “这个角色是谁”多行输入 | 身份图块（选中后自动填一句底稿）+ 可编辑的多行框 | 内置身份和对应底稿 |
| 开始新故事 03 | 短 / 适中 / 长 | 用行数图示的三格分段 | 无 |
| 开始新故事 04 | 文风输入框 | 多选标签 + 自定义，拼成文本（≤200 字） | 内置标签列表 |
| 开始新故事 05 | “不想看到”输入框 | 勾选清单 + 其他，拼成文本（≤300 字） | 内置清单 |
| 添加密钥 | 服务商分段 + 端点输入 | 服务商图块 + “使用官方地址”勾选（默认勾上；选自定义时去掉勾选，显示输入框） | 无 |
| 密钥详情 | 模型名输入 + 获取列表 | 自动拉取的单选列表，搜索框兼做手动输入 | 进入页面时自动获取一次 |
| 连接测试 | 时长输入框 | 30s / 60s / 2m / 5m 分段 | 无 |
| 阅读页 | 无 | “更多”菜单里的阅读设置 | 本地保存字体和字号 |
| 剧本库 | 列表 | 网格 / 列表切换；没有图片的角色卡用几何封面 | 按卡片 ID 从 5 种母题里确定性地选一种（见 `Main.png` 的“几何封面”） |

还没有界面、这次补上了入口的后端能力：

- **世界状态：** 人物与地点、关系图、事实；揭示秘密前要确认。
- **重命名：** 故事和剧本都可以重命名，入口是列表左滑或长按，以及详情页的“更多”菜单。
- **编辑密钥：** 改备注名和端点，入口是密钥详情标题旁的铅笔。
- **取消导演模型：** 入口是导演模型页底部的红字按钮。

## 不要照抄的部分

- 画板外壳（`.tag` 编号条、多屏并排的布局）、键盘占位区、截图里的状态栏留白。
- 截图里的等宽字体如果显示成系统等宽字体，属于截图环境的问题，实际应该用 IBM Plex Mono。
