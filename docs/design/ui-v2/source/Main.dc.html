BetterTavern · Design Language 02

白，线，
直角。

像一个干净的文档工具，而不是游戏界面。白色是主色，1px 线条负责分区，所有角都是 90°。能点的不让打，能用图标说的不写一句话。故事正文是唯一用宋体的地方，其他所有界面都退成黑白。

01
白为底
背景只有两层：纯白 #FFFFFF 和极浅灰 #F7F7F5。不使用渐变、色块卡片，也没有大面积阴影。
02
一像素
层级靠 1px 线：浅线 #E8E8E5 分隔列表行，深线 #111111 标出区块起点和选中项。
03
九十度
圆角一律为 0。图标也用方头描边、尖角转折，和按钮的直角是同一套语言。
04
选，而不是写
能列举的选项都做成标签、勾选、分段或下拉。只有名字、密钥、自由行动这三处保留输入框。
Color

色板

黑白负责大部分画面；蓝只用于“我”和选中态；红、绿、琥珀只表示状态，并且总是配着图标出现。

Type

字体

界面用系统黑体（苹方 / Noto Sans CJK），不打包字体。数字和标签用 IBM Plex Mono（约 60 KB）。叙述正文用思源宋体的常用字子集（约 4–6 MB），在阅读设置里可以切换成黑体。
