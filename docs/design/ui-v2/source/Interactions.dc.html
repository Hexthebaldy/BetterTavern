BetterTavern · Interaction

读不打扰，
动手在拇指下。

顶部只放低频入口（返回、世界、更多），所有回合操作都在屏幕下三分之一。行动栏只换内容，不换位置。

01

滚动跟随

跟随中新字出现就贴底
手指拖离
> 80pt
暂停跟随浮出“回到最新”
点按钮或
滑回底部
跟随中滚到底
a只认手指。内容变长时程序滚动触发的事件不算“翻走”，只有拖动和惯性滚动才会关掉跟随（沿用现有 StoryFeed 的逻辑）。
b打开就停在最新一段。往上翻到顶，是一页书名页：封面、标题，以及“我是谁”。
c出字不跳。新字只追加在最后一个文本节点，120ms 淡入；光标是 2px 宽的蓝色竖条，不闪烁；已经写完的回合不跟着流式输出重新渲染。
d动态字体与读屏。正文跟随系统字号（15–24pt），“更多”菜单里可以单独调阅读字号，也可以在宋体和黑体之间切换。每段写完后整段播报，行动前隐藏地读出“我的行动：”。
02

行动栏状态

A / B 选项两行 + 自己写
没有选项直接是输入框
自由输入聚焦、收起、发送
发送中选中项变蓝
生成中蓝线扫动 + 停止
失败重试 / 去设置模型；换个行动 / 关闭
开场没写只有“开始故事”
同步中暂时锁住
a顶边就是状态灯。行动栏顶边的 1px 线会变色：空闲时黑，生成中有蓝色扫动，重连时变琥珀，失败时变红。
b防重复提交。点下选项后它立刻变成蓝底，其他选项变灰，直到服务端确认；自动重试不会重复提交（沿用现有逻辑）。
c键盘与返回键。输入框跟着键盘上移，收起键盘不清空草稿。剩 200 字以内时在“收起”旁边显示“剩 186”。Android 返回键依次：收起输入框 → 关闭面板 → 离开阅读页；离开时生成不会中断。
