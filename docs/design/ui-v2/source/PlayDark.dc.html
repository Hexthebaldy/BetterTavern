雨夜渡口

我推开茶馆的门，檐下的铜铃响了两声。柜台后的女人没有抬头，只把一只粗瓷杯推到桌沿：“最后一班船已经走了。客人要等，就得等到明天。”

我在她对面坐下，问她这道疤是怎么来的。

沈知微终于抬起眼。那是一双很静的眼睛，静得让我想起深夜无人的河面。

“客人问得太多了。”她往我杯里续了茶，水声很轻，“在这个渡口，问得多的人，往往走不了。”

窗外忽然传来船桨拍水的声音——可最后一班船，明明已经走了。
