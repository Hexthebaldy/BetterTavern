# 隐私政策

生效日期：2026 年 10 月 23 日

本政策说明 BetterTavern（以下称“本服务”，由个人开发者运营，以下称“我们”）收集哪些信息、怎么使用、交给谁、保存多久，以及你能做什么。

## 1. 我们收集的信息

**账号信息**：邮箱、昵称、注册时选的界面语言。密码只保存不可逆的哈希值（Argon2），我们看不到你的密码。

**你创作的内容**：故事和每一段的文字、角色卡、剧本、工作台的草稿和对话、你上传或生成的图片、agent 查资料时读过的网页和记下的笔记。

**你填写的 API Key**：模型、搜索、读网页、文生图服务的 Key。它们用服务器上的主密钥加密后保存，界面上只显示最后四位。

**点数记录**：使用官方模型时，我们记录每次调用用了哪个模型、多少 token、扣了多少点数，不记录内容。为了让同一个邮箱只领一次体验额度，我们还保存邮箱的不可逆哈希值。

**登录信息**：为了让你保持登录，服务器会签发登录令牌。网页端只在浏览器里保存一个用于续期登录的 Cookie（HttpOnly，页面脚本读不到），不使用任何广告或统计用的 Cookie。

**运行日志**：为了排查问题和防止滥用，服务器会记录请求的时间、地址、结果和耗时。应用日志里用一个不可逆的代号代替你的账号，不记录故事的文字和 API Key。反向代理的访问日志会记录 IP 地址，保留约两周。

我们不收集你的真实姓名、电话、位置、通讯录，也不使用第三方统计或广告工具。

## 2. 我们怎么使用这些信息

- 提供本服务：保存你的内容，按你的操作调用你接入的服务；
- 计算点数：按官方模型的用量扣点数，估计你还能写多少回合；
- 检查内容：角色卡保存进仓库之前，由 AI 自动检查有没有违反[内容规则](/rules)的色情内容，结果只用来决定能不能保存；
- 发送必要的邮件：注册验证码、找回密码的验证码；
- 安全和防滥用：频率限制、发现异常登录和攻击；
- 排查问题：服务出错时，我们会收到只包含错误类型和次数的提醒，不包含你的内容。

我们不会出售你的信息，不会用你的内容做广告，也不会用你的内容训练 AI 模型。除非为了处理你的求助、排查你报告的问题、处理违规举报或依法要求，我们不会查看你的内容。

## 3. 我们把信息交给谁

只交给提供本服务所必需的服务商：

- **官方模型**：使用官方模型写故事、写卡时，以及角色卡保存前的内容检查，你的输入、角色卡和故事上下文会发给 DeepSeek（深度求索）处理。DeepSeek 的服务器在中国。
- **你接入的服务**：写故事、写卡时，你的输入、角色卡和故事上下文会发给你选择的模型服务商；联网搜索的关键词、要读的网页地址、生成图片的描述会发给你接入的对应服务。它们怎么处理这些数据，请看它们各自的隐私政策。
- **服务器和网络**：本服务的服务器在新加坡（Vultr）；网站经过 Cloudflare 的网络加速和防护，Cloudflare 会处理你的 IP 地址和访问流量。
- **邮件**：验证码邮件通过 Resend 发送，Resend 会处理你的邮箱地址和邮件内容。

如果法律要求，我们可能需要向有关部门提供信息。

## 4. 跨境传输

本服务的服务器在新加坡，上面列出的服务商可能在其他国家或地区处理数据。其中，使用官方模型时你的内容会发到中国的 DeepSeek 处理；不想这样的话，可以在设置里换成自己接入的模型。使用本服务即表示你同意你的信息在这些地方存储和处理。

## 5. 保存多久

- 账号和你创作的内容：保存到你删除它们或删除账号为止；
- 删除账号：账号和全部数据立即从数据库中删除。备份（服务器整机的自动备份、升级前的数据库备份）里的副本会在备份轮换后清除，一般不超过数周；
- 点数记录：保存到你删除账号为止；
- 领过体验额度的邮箱哈希：删除账号后仍然保留，用来防止同一个邮箱重复领取；
- 注册后 24 小时内没有验证邮箱的账号：自动删除；
- 验证码：15 分钟内有效，用过或过期后删除；
- agent 读过的网页缓存：7 天；
- 运行日志：按大小或时间轮转，一般保留几天到几周。

## 6. 安全

数据在网络上传输时用 HTTPS 加密；API Key 加密保存；密码只保存哈希。但没有任何系统是绝对安全的，请为本服务设置一个不和其他网站共用的密码。

## 7. 你的权利

- 查看和修改：你可以随时在应用里查看自己的内容，修改密码；
- 删除：你可以删除单个故事、角色卡、剧本、草稿，也可以在“设置 › 账户”里删除整个账号；
- 其他请求（例如想要一份你的数据）：发邮件到 support@bettertavern.com，我们会在合理的时间内回复。

## 8. 未成年人

本服务只面向年满 18 周岁的人。如果我们发现未成年人注册了账号，会删除该账号。

## 9. 政策的修改

我们可能修改本政策。修改后会在本页更新生效日期；重大变更会通过网站或邮件提前告知。

## 10. 联系我们

对本政策有任何问题，请发邮件到 support@bettertavern.com。
