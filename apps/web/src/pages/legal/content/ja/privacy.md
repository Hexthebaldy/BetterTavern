# プライバシーポリシー

施行日：2026 年 10 月 23 日

このポリシーでは、BetterTavern（以下「本サービス」。個人開発者（以下「運営者」）が運営）が、どんな情報を集め、どう使い、誰に渡し、どれくらい保存するのか、そしてあなたにできることを説明します。

## 1. 集める情報

**アカウント情報**：メールアドレス、ニックネーム、登録時に選んだ表示言語。パスワードは元に戻せないハッシュ（Argon2）としてのみ保存し、運営者はパスワードを見ることができません。

**あなたが作ったもの**：物語と各パートの文章、キャラクターカード、シナリオ、ワークベンチの下書きと会話、アップロードまたは生成した画像、エージェントが調べもので読んだ Web ページと記録したメモ。

**入力された API キー**：モデル、検索、ページの読み込み、画像生成サービスのキー。サーバー上のマスターキーで暗号化して保存し、アプリには末尾 4 文字しか表示しません。

**ポイントの記録**：公式モデルを使ったとき、呼び出しごとに使ったモデル、トークン数、消費したポイントを記録します。内容は記録しません。また、同じメールアドレスでお試しポイントを一度しか受け取れないようにするため、メールアドレスの元に戻せないハッシュを保存します。

**ログイン情報**：ログイン状態を保つため、サーバーはログイン用のトークンを発行します。Web 版では、ログインを更新するための Cookie を 1 つだけブラウザに保存します（HttpOnly のため、ページのスクリプトからは読めません）。広告や解析のための Cookie は使いません。

**ログ**：不具合の調査と不正利用の防止のため、サーバーはリクエストの日時、アドレス、結果、処理時間を記録します。アプリのログではアカウントを元に戻せない符号で表し、物語の文章や API キーは記録しません。リバースプロキシのアクセスログには IP アドレスが記録され、約 2 週間保存されます。

本名、電話番号、位置情報、連絡先は集めません。第三者の解析ツールや広告ツールも使いません。

## 2. 情報の使い道

- 本サービスの提供：あなたのコンテンツを保存し、あなたの操作に応じて接続したサービスを呼び出す
- ポイントの計算：公式モデルの使用量に応じたポイントの消費と、あと何ターン書けるかの目安の計算
- 必要なメールの送信：登録時の確認コード、パスワード再設定の確認コード
- セキュリティと不正利用の防止：回数制限、不審なログインや攻撃の検知
- 不具合の調査：エラーが起きたとき、運営者はエラーの種類と回数だけを含む通知を受け取ります。あなたのコンテンツは含まれません。

あなたの情報を売ったり、コンテンツを広告に使ったり、AI モデルの学習に使ったりはしません。サポートへの対応、報告された不具合の調査、違反の通報への対応、法令による要請の場合を除き、あなたのコンテンツを見ることはありません。

## 3. 情報を渡す相手

本サービスの運営に必要な事業者にだけ渡します。

- **公式モデル**：公式モデルで物語やカードを書くとき、あなたの入力、キャラクターカード、物語の文脈は DeepSeek に送られて処理されます。DeepSeek のサーバーは中国にあります。
- **接続したサービス**：物語やカードを書くとき、あなたの入力、キャラクターカード、物語の文脈は、あなたが選んだモデル提供者に送られます。検索キーワード、読み込むページのアドレス、画像の説明は、接続した対応するサービスに送られます。それぞれの扱いについては、各サービスのプライバシーポリシーをご覧ください。
- **サーバーとネットワーク**：本サービスのサーバーはシンガポール（Vultr）にあります。Web サイトは高速化と保護のため Cloudflare のネットワークを経由し、Cloudflare があなたの IP アドレスと通信を処理します。
- **メール**：確認メールは Resend から送信され、Resend があなたのメールアドレスとメールの内容を処理します。

法令で求められた場合、関係機関に情報を提供することがあります。

## 4. 国外への移転

本サービスのサーバーはシンガポールにあり、上記の事業者は他の国や地域でデータを処理することがあります。特に、公式モデルを使うとあなたのコンテンツは中国の DeepSeek に送られて処理されます。それを避けたい場合は、設定画面で自分で接続したモデルに切り替えられます。本サービスを利用することで、あなたの情報がそれらの場所で保存・処理されることに同意したものとみなします。

## 5. 保存期間

- アカウントとあなたが作ったもの：あなたが削除するか、アカウントを削除するまで
- アカウントの削除：アカウントとすべてのデータはただちにデータベースから削除されます。バックアップ（サーバーの自動バックアップ、アップデート前のデータベースのバックアップ）に残るコピーは、バックアップの入れ替わりとともに、通常数週間以内に削除されます
- ポイントの記録：アカウントを削除するまで
- お試しポイントを受け取ったメールアドレスのハッシュ：同じメールアドレスでの重複受け取りを防ぐため、アカウントの削除後も保存
- 登録から 24 時間以内にメールアドレスが確認されなかったアカウント：自動的に削除
- 確認コード：15 分間有効で、使用済みまたは期限切れになると削除
- エージェントが読んだ Web ページのキャッシュ：7 日間
- ログ：サイズまたは期間でローテーションされ、通常は数日から数週間保存

## 6. セキュリティ

通信は HTTPS で暗号化し、API キーは暗号化して保存し、パスワードはハッシュとしてのみ保存します。ただし、完全に安全なシステムはありません。本サービスには、他のサイトと使い回さないパスワードを設定してください。

## 7. あなたの権利

- 確認と変更：アプリでいつでも自分のコンテンツを確認でき、パスワードを変更できます
- 削除：物語、キャラクターカード、シナリオ、下書きを個別に削除できるほか、「設定 › アカウント」からアカウント全体を削除できます
- その他のご依頼（データのコピーがほしい場合など）：support@bettertavern.com までメールでご連絡ください。合理的な期間内にお返事します。

## 8. 未成年の方

本サービスは 18 歳以上の方のみを対象としています。未成年の方の登録が判明した場合、そのアカウントを削除します。

## 9. ポリシーの変更

運営者は本ポリシーを変更することがあります。変更した場合はこのページの施行日を更新し、重要な変更はサイトまたはメールで事前にお知らせします。

## 10. お問い合わせ

本ポリシーに関するご質問は support@bettertavern.com までメールでお問い合わせください。
